## 8. ขั้นตอนถัดไปที่แนะนำ

1. ให้ DBA ตรวจ `docs/SCHEMA-CHECKLIST.md` หัวข้อ B และ C แล้วแก้ชื่อตาราง/คอลัมน์ในสคริปต์ 03 และ 04
2. ขอคำตอบ **OI-01** จากฝ่ายธุรกิจ (กระทบตัวเลขในรายงานโดยตรง)
3. รันสคริปต์ SQL บนฐานข้อมูลทดสอบ แล้วตรวจผลลัพธ์กับตัวอย่างในไฟล์เงื่อนไขของ CR
4. `sh tools/make_import_files.sh` แล้ว Import เข้า `cle_report.pbl` → Full Build → แก้ Compile error ที่เหลือ
5. ผูกเมนู (สาขา ข้อ 53 / สำนักงานใหญ่ ข้อ 38)
6. ทดสอบตามกรณีทดสอบใน `CR95968-05-STP` ทั้ง 54 กรณี แล้วบันทึกผลลงตารางในเอกสาร
7. ให้ผู้มีอำนาจลงนามในเอกสาร ISO ทั้ง 10 ฉบับ (ปัจจุบันสถานะ "รอพิจารณา" ทุกฉบับ)
